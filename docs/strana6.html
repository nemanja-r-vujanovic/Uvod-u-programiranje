<< Uputstvo za instalaciju Visual Studio Code

• Sačekajte nekoliko trenutaka da se snimak učita i prikaže na stranici, a zatim pratite korake za reprodukciju (koraci se nalaze ispod snimka).

Pristup preko telefona ‣ 1. Kliknite na dugme "Play video" (na sredini ekrana). Nemojte birati opciju "Open in browser" (u donjem desnom uglu);
‣ 2. Pauzirajte video pritiskom na "Alt + K";
‣ 3. U donjem desnom uglu izaberite "Playback options" → "Quality" → "1080p" kako biste podesili kvalitet snimka;
‣ 4. Pređite u režim prikaza preko celog ekrana pritiskom na "Alt + Enter";
‣ 5. Nastavite reprodukciju snimka pritiskom na "Alt + K".
